Set up safely

Choose your app below. These settings help keep class exercises separate from your other work.

I use ChatGPT ↓ I use Claude ↓

First, make a practice folder

Create a folder called AI Course Practice. Put only the course's fictional files there. Keep an untouched copy of those files somewhere else. When the app asks for access, choose this folder—not your whole Desktop, Documents folder, or cloud drive.

Do not use private records, passwords, or confidential work files for the first exercises. A paid account does not change your work or school rules.

CHATGPT PLUS · DESKTOP APP

Your ChatGPT settings

  1. Switch off optional AI training. Open Settings → Data controls. If you see “Improve the model for everyone,” switch it off. If Data controls are not in the desktop app, check your ChatGPT account settings on the web. Where to find data controls
  2. Keep old chats out of class exercises. Open Settings → Personalization and turn off memory if your account offers it. This keeps details from one exercise from carrying into another. About ChatGPT memory
  3. Stay in charge of actions. For a local file task, find the permission choice below the message box. Select Ask for approval, not Full access. The app may still edit files inside the folder you chose, so ask it to show you a plan before it makes changes. About permission choices
  4. Leave broad access off. You do not need Computer History, connected email, or a signed-in browser for the first exercises. If browser permissions appear, choose Always ask where available. About browser permissions

CLAUDE PRO · DESKTOP APP

Your Claude settings

  1. Switch off optional AI training. Open Settings → Privacy and switch off Help Improve our AI models. About this setting
  2. Keep old chats out of class exercises. Open Settings → Memory, switch off Generate memory from chats, and choose Pause memory. If you see Search and reference chats, switch that off too. Do not choose Reset memory unless you intend to erase memories you already have. About Claude memory
  3. Stay in charge of actions. In the message-box permission choice, select Manual or Manually approve, not automatic approval. This keeps you in the loop when Claude wants to take an action. About Claude permissions
  4. Leave broad access off. Leave Settings → General → Enable computer use off for folder exercises. You do not need to connect email, messaging, or other accounts. About computer use

Your Claude screen may say “Cowork,” or it may simply say “Claude.” Both can support file tasks. For this exercise, use a regular conversation; Claude's Incognito mode currently cannot create files. About the new interface

ONE-MINUTE TEST

Ask for a plan, not a change

Start a new file task with the AI Course Practice folder. Paste this:

These are fictional files for a class exercise. Tell me which files you can access, then suggest how to organize them. Show the current and proposed file names. Do not move, rename, delete, share, or send anything yet. Wait for me to review your plan.

The app should propose a plan and leave the files untouched. If it asks to see more of your computer or another account, decline and ask an instructor.

These choices reduce unnecessary access and carry-over between exercises. They do not make either app offline: the provider may still process your prompts and relevant file content to do the task. For class, ask the AI to draft messages, not send them. ChatGPT data explanation · Claude safety guidance
