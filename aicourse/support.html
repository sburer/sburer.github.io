A quick file tutorial

How to use a ZIP file

A ZIP is a package that holds a whole folder of files. Download it, extract it (also called “unzip”), and work in the new folder—not inside the ZIP.

  1. 1Download one packet. Choose a packet on the Materials page. Look for the file ending in .zip in your Downloads folder.
  2. 2Extract all its files. On a Mac, double-click the ZIP. On Windows, right-click it, choose Extract All…, and then choose Extract. A new folder will appear.
  3. 3Open the new folder. For a Day 1 or Day 2 packet, find and open participant-master. Inside it, start with the Day 1 Student Guide.docx or Day 2 Student Guide.docx. You can also read START-HERE.md.
  4. 4Make a practice copy. Duplicate the entire participant-master folder and work on the copy. Leave the original untouched so you can start over if you need to.
Using both days? Extract each packet into its own place. Both main packets contain a folder called participant-master, so don’t combine them. Keep the “fresh batch” ZIP separate until the Day 2 exercise asks for it.

Only seeing a preview of the ZIP? Go back to Downloads and extract the whole package first. Look beside the ZIP for the new folder. If the folder is already there, your browser may have unpacked it for you. For more help, see Apple’s Mac instructions or Microsoft’s Windows instructions.
