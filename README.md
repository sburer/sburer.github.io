# sburer.github.io

## AI course site

The course lives in `aicourse/`. Its footer shows a site-wide `YYYY.MM.DD.N` revision (the presentation shows it at the bottom of each slide). Increment that revision on all course HTML pages whenever publishing a site change. When CSS changes, also change the `styles.css?v=...` query on every page so visitors do not see a cached stylesheet with new HTML.
